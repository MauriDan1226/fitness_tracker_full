Aplicación web de seguimiento fitness: registro de entrenamientos, metas personales,
estadísticas de progreso y consejos de salud personalizados.

## Stack

- **Frontend:** React + Vite, JavaScript (JSX), CSS puro, Recharts
- **Backend:** Node.js + Express
- **Base de datos:** MongoDB + Mongoose
- **Autenticación:** JWT + bcrypt

## Estructura del repositorio

```
fitness_tracker_full/
├── backend/     API REST (Express + MongoDB)
└── frontend/    Cliente web (React + Vite)
```
